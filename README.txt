ABZ GLOBAL — CLEAN WEBSITE PACKAGE

Готовый статический сайт. Все рабочие файлы лежат в корне архива.
Никакие установка, сборка или ключи API не нужны.

GITHUB → NETLIFY
1. Распакуйте ZIP.
2. Загрузите всё содержимое в корень репозитория сайта с заменой старых файлов.
   index.html должен находиться в корне, а не во вложенной папке ABZ-Global.
3. Сохраните изменения (Commit changes).
4. Для Netlify: Build command — пусто, Publish directory — точка (.).
   netlify.toml уже содержит папку публикации.
5. Проверьте обновлённый сайт после завершения публикации.

NETLIFY ВРУЧНУЮ
Распакуйте ZIP и перетащите папку с index.html в окно ручной загрузки сайта.

ПРОСМОТР НА КОМПЬЮТЕРЕ
Откройте index.html браузером. Изображения, меню и ссылки работают без сервера.

RECRUITING
Единственный адрес: hr@abzglobalhr.com
Все SEND YOUR RESUME / EMAIL YOUR RESUME открывают mailto с темой письма.
Кандидат сам прикрепляет резюме и отправляет письмо. Mailto не прикрепляет
файлы автоматически. Если почтовая программа не настроена, адрес можно
скопировать в веб-почту. Анкет, регистрации и загрузки персональных данных нет.

ИЗОБРАЖЕНИЯ
Четыре WebP-фотографии и четыре облегчённые версии *-small.webp.
Фотографии отображаются в исходных пропорциях: width:100%, height:auto.
Рекламные надписи вынесены в HTML. Фото не используются как cover-фон.
Это художественные изображения, обработанные AI на основе материалов
предыдущего сайта; они не подтверждают фактический состав автопарка.
Неподтверждённые DOT/MC и регистрационные номера удалены с изображений.
